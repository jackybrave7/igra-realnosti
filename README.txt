ИГРЫ РЕАЛЬНОСТИ — статический сайт-прототип

Публикация на Vercel:
1. Распакуйте архив.
2. Откройте https://vercel.com/new
3. Импортируйте папку/репозиторий проекта (удобнее сначала загрузить файлы в GitHub).
4. Framework Preset: Other; Build Command: пусто; Output Directory: ./
5. Нажмите Deploy.

Сайт не требует сборки: главная страница — index.html.
Форма заявки пока демонстрационная и не отправляет данные.
Изображения загружаются из Unsplash по сети.
